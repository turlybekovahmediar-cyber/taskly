# Taskly

Taskly — это площадка, где малый бизнес находит исполнителей для небольших задач, а студенты и начинающие специалисты получают первые реальные проекты.

Идея простая: у малого бизнеса постоянно есть задачи вроде «сделать лендинг», «свести таблицы», «написать посты», но на агентство нет денег, а фрилансеры с бирж часто пропадают или делают не то. С другой стороны, у студентов есть навыки, но без опыта их никуда не берут. Мы соединяем эти две стороны и делаем сделку безопасной для обеих.

Как это работает:
- бизнес описывает задачу через пошаговый мастер — на выходе получается понятное ТЗ;
- специалисты откликаются с ценой и сроком, бизнес выбирает исполнителя;
- оплата резервируется заранее и уходит исполнителю только после приёмки работы;
- в проекте есть этапы, переписка, правки (их количество фиксируется в ТЗ) и отзывы;
- мы берём комиссию 5% с исполнителя и только за завершённые проекты.

**Сайт:** https://taskly-edsi.onrender.com

Чтобы быстро посмотреть продукт, на странице входа есть кнопки демо-входа за компанию Barber Loft и за специалиста Аружан. Можно и зарегистрироваться самому.

## Технологии

- Фронтенд: React + Vite
- Бэкенд: Node.js + Express
- База данных: PostgreSQL (Neon)
- Хостинг: Render

Сервер отдаёт и API, и сам сайт, поэтому всё работает по одной ссылке.

В базе хранятся пользователи (один аккаунт может быть и заказчиком, и исполнителем), профили компаний и специалистов, проекты, отклики, платежи, сообщения, файлы, изменения условий, отзывы и уведомления. Схема лежит в `backend/src/schema.sql`.

Статусы проекта идут по цепочке: поиск исполнителя → ожидает оплаты → в работе → на проверке → завершён (с возможностью вернуть на правку). Сервер сам проверяет, кто и на каком этапе может что делать, — например, принять работу может только заказчик и только после того, как исполнитель её сдал.

## Основные запросы API

- `POST /api/auth/register`, `POST /api/auth/login`, `POST /api/auth/logout` — регистрация и вход
- `GET /api/state` — данные для текущего пользователя
- `POST /api/projects` — опубликовать проект
- `POST /api/projects/:id/proposals` — откликнуться на проект
- `POST /api/projects/:id/select` — выбрать исполнителя
- `POST /api/projects/:id/payment` — зарезервировать оплату
- `POST /api/projects/:id/deliver` — сдать работу
- `POST /api/projects/:id/request-fix` — попросить правку
- `POST /api/projects/:id/accept` — принять работу
- `POST /api/projects/:id/reviews` — оставить отзыв
- `POST /api/projects/:id/messages` — написать в чат проекта

Остальные (профиль, приглашения, изменения условий, уведомления) лежат в `backend/src/routes`.

## Как запустить у себя

Нужен Node.js 20 или новее и база PostgreSQL (мы брали бесплатную на neon.tech).

1. Скопировать `backend/.env.example` в `backend/.env` и вписать строку подключения к базе и любой длинный `JWT_SECRET`.
2. Запустить:
   ```
   npm run build
   npm start
   ```
   На Windows можно просто запустить `start.cmd`.
3. Открыть http://localhost:3000

При первом запуске сервер сам создаст таблицы и заполнит базу демо-данными.

Для разработки удобнее запускать отдельно: `npm run dev:api` и `npm run dev:web` (сайт будет на http://localhost:5173).

## Деплой

Сайт развёрнут на Render, база — в Neon. Настройки для Render лежат в `render.yaml`, в переменных окружения нужно указать `DATABASE_URL`.
