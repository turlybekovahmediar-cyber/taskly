# Taskly — фронтенд

React 18 + Vite. Данные приходят с бэкенда (`../backend`) через `/api`. Общее описание, API и деплой — в [README в корне](../README.md).

## Запуск для разработки

Сначала запустите API (`npm run dev --prefix ../backend`, порт 3000), потом:

```bash
npm install
npm run dev
```

Откроется http://localhost:5173. Запросы `/api` Vite проксирует на http://localhost:3000 (см. `vite.config.js`).

Сборка: `npm run build` → `dist/`. В продакшене `dist/` отдаёт тот же сервер, что и API.

## Структура

```
src/
  main.jsx            маршруты, проверка доступа по роли, обработка ошибок страниц
  lib/api.js          запросы к бэкенду
  lib/router.js       роутер на History API (чистые URL)
  lib/format.js       деньги, комиссия 5%, склонения, даты
  data/mock.js        справочники (направления, навыки, статусы) и исходные демо-данные для seed бэкенда
  store/store.jsx     состояние с сервера и действия; каждое действие = запрос к API
  components/         ui (примитивы), shell (шапка, футер, кабинет, демо-панель), chat
  pages/              public, auth, business, businessDeal, workspace, specialist, meta
  styles/             tokens.css (переменные дизайна), components.css
public/fonts/         Onest (кириллица, казахские буквы, латиница, ₸)
```

## Демо

- На странице «Вход» — быстрый вход в демо-аккаунты: бизнес Barber Loft и специалист Аружан Смагулова.
- В демо-аккаунтах переключение роли открывает второй демо-аккаунт — так видна сделка с обеих сторон.
- Кнопка «Демо» внизу слева: роль, режим «пустой аккаунт», акцент/плотность/радиусы, сброс демо-данных (только в демо-аккаунте).
- Сквозной сценарий: `/biz/projects/p-1041/proposals` → выбрать исполнителя → подтвердить условия → зарезервировать оплату → в роли специалиста сдать результат → в роли бизнеса принять работу и оставить отзыв.
